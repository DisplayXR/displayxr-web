Live DIBR — dev page

Synthetic 720p clip + analytic ground-truth disparity (364×210 @ 12 fps) through createLiveDibr. On a DisplayXR browser the canvas is woven via createInline3D + addScene; elsewhere it shows the side-by-side views from simulated Kooima eyes (?views=N for a multiview fan, ?eye=0.2 for the per-view spacing in IPDs, default 1). Off-axis viewer, in metres: ?eyeY=0.1&dist=0.55 (+ eyeX, tileH = the tile's physical height, default 0.1008 m = the 1.0.2 panel test's 800×450 CSS tile); ?panel uses the two projection matrices dumped from that panel run verbatim.
