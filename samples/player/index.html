A media title with real transport — play/pause/seek/mute from an SDK-drawn bar or the keyboard (Space/K, ←/→, J/L, M) — in one addPlayer() call, built on wall.addVideo(). On the DisplayXR Browser the left tile weaves to glasses-free 3D; the right tile is deliberately flat (format:'mono') even there. Anywhere else both render as ordinary 2D video.

format:'sbs' (default)

The clip is a real side-by-side stereo encode — left half is left-eye content, right half is right-eye content. Woven, it has depth. The chips call setSource(), which crossfades from the outgoing frame (transition:'crossfade'); F or the corner button goes full screen.

format:'mono'

The SAME stereo file, told it is flat — so it is painted whole, and you see both eyes side by side, squeezed. That is correct: 'mono' is for genuinely 2D titles (a trailer, a 2D entry in a mixed catalogue), where "whole" is the picture. This sample has no 2D asset, so it shows what the mode does rather than what it is for.
