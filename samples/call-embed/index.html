call embed

The one-line 3D call widget. The <dxr-call> element below is mounted with no options at all: hosted signalling, the best camera it can find, the SDK's own lobby, invite link + QR and controls. Start a call here, send the link to someone (or open it in a second browser), and up to four people are in it. On the DisplayXR Browser with a 3D display the other people are in glasses-free 3D — a stereo camera is sent as a real side-by-side pair and converged on the face, a plain webcam is lifted from 2D to 3D on the receiving side. In any other browser it is the same call, fully working, in 2D.

<script type="module">
  const el = document.querySelector('dxr-call');
  el.addEventListener('dxr-call:joined', (e) => console.log('in room', e.detail.room));
  el.addEventListener('dxr-call:error',  (e) => console.warn(e.detail.code, e.detail.message));
</script>
npm — a bundled app (2D→3D lift included) app.js 
import { mountCall } from '@displayxr/inline3d/call/full';

const call = await mountCall(document.getElementById('call'));
call.on('peer', ({ id }) => console.log('peer', id));
shareBtn.onclick = () => navigator.share({ url: call.inviteLink() });
The room travels in the invite link's #room= fragment, which the browser never sends to any server; the signalling server relays only WebRTC offers, answers and ICE candidates, and never sees audio or video (media is DTLS-SRTP between the browsers). Attributes: room · signaling (your own dxr-signal/1 server) · camera (auto|stereo|mono|deviceId) · layout (grid|speaker) · accent · max-peers · no-ui · auto-join · mono3d="off". Non-string options (a MediaStream, a custom adapter) go on el.options before the element connects; the handle is el.call. URL params on this page: ?signal=dev uses node signaling/dev-server.mjs on ws://localhost:8787, ?signal=wss://… your own server, ?accent=violet, ?layout=speaker. Developer guide: docs/call.md (options, events, headless, theming, React, self-hosting, troubleshooting). Preview tier — sdk-stability.md, RFC 0003. The explicit addCall() form with test switches (synthetic stereo pair, lift toggles) is samples/call/. Get the DisplayXR Browser.
