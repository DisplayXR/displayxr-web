Embeddable 3D video player — @displayxr/inline3d/player

A side-by-side 3D video with play/pause, loop, scrubber, mute and fullscreen. Glasses-free 3D in the DisplayXR Browser; a normal 2D video (left eye) everywhere else.

Factory API

Custom element (drop-in HTML)

Embed it in your page

<script type="module">
  import '@displayxr/inline3d/player';         // defines <dxr-video-player>
</script>
<dxr-video-player src="movie_sbs.webm" loop autoplay></dxr-video-player>

// …or drive it from JS:
import { createVideoPlayer } from '@displayxr/inline3d/player';
const p = createVideoPlayer(document.getElementById('host'), {
  src: 'movie_sbs.webm', loop: true, autoplay: false,
});
p.play(); p.pause(); p.setLoop(false); p.enterFullscreen();

Source must be a side-by-side VP9/WebM (left eye = left half), ~640×360 per eye. See samples/video/README.md for the ffmpeg recipe.
